# Student Portfolio and Academic Management Website

A responsive multi-page portfolio built for **COS 106: Introduction to Web Technologies** at Miva Open University.

**Author:** Aanukanmi Adewuyi (Jemmie)
**Live site:** https://jemmiesweety-dev.github.io/Portfolio-Website/
**Repository:** https://github.com/jemmiesweety-DEV/Portfolio-Website

## Pages

| Page | File | What it does |
|------|------|--------------|
| Home | `index.html` | Name, photo, welcome message, short bio, audio introduction |
| About | `about.html` | Education table, career aspirations, skills, hobbies |
| Projects | `projects.html` | Three projects with descriptions, screenshots, and links |
| Academic Planner | `planner.html` | Add, complete, and delete tasks (JavaScript) |
| Contact | `contact.html` | Form with JavaScript validation |
| Stock Tracker | `stock-tracker.html` | Project: track pharmacy stock levels |
| Scheduler | `scheduler.html` | Project: book front desk appointments |

## Technologies

- **HTML5:** semantic elements, forms, tables, lists, images, links, audio
- **CSS3:** external stylesheet, Flexbox, CSS Grid, responsive design, transitions and animations, CSS variables
- **JavaScript:** event handling, DOM manipulation, form validation, arrays and functions, localStorage

## File structure

All files sit together in the main folder of the repository:

```
index.html  about.html  projects.html  planner.html
contact.html  stock-tracker.html  scheduler.html   the seven pages
style.css        one stylesheet shared by every page
main.js          mobile menu (all pages)
planner.js       academic planner
contact.js       contact form validation
stock.js         stock tracker
scheduler.js     appointment scheduler
profile.jpg      my photograph
project-*.png    project screenshots
intro.mp3  intro.m4a    audio introduction
```

## Run locally

Open `index.html` in a browser, or use the Live Server extension in VS Code.
